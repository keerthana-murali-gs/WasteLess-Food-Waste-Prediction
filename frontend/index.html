WasteLess

Food Waste Prediction & Kitchen Management System. An AI-powered solution built to forecast daily food consumption, eliminate kitchen overproduction, and slash commercial food waste.

Open Dashboard Demand Prediction
Member 1 – Frontend Module
UI/UX, Responsive Views & Interactive Charts

Developed independently inside the frontend/ directory with Bootstrap 5, HTML, CSS, JavaScript, and Chart.js. Includes built-in realistic mock data so it runs standalone even without a backend!

  • 7 responsive pages (Dashboard, Food, Records, Prediction, Reports)
  • Live leftover and waste % calculators as you type
  • Clean REST API abstraction in js/api.js
Member 2 – Backend & ML Module
Flask REST APIs, SQLite Database & Scikit-Learn

Developed in backend/ with Python Flask, SQLAlchemy, and SQLite. Features time-series demand forecasting with Linear Regression & Random Forest trained on 1,090+ historical records.

  • Fully documented RESTful endpoints with JSON responses
  • Linear Regression baseline with 9.24 MAE & Random Forest with 6.90 MAE
  • SQLite storage with auto-seeding & CORS enabled
